# Pizza Shop Next

A full-stack online pizza shop built with Next.js. The app includes product browsing, category navigation, filters, cart/checkout flow, authentication, and payment integration.

## Live Demo

- [pizza-shop-next.vercel.app](https://pizza-shop-next.vercel.app/)

## Tech Stack

- Next.js 14 (App Router)
- React 18 + TypeScript
- Tailwind CSS + shadcn/ui + Radix UI
- Zustand (state management)
- React Hook Form + Zod (form validation)
- NextAuth.js (authentication)
- Prisma ORM + PostgreSQL
- Stripe (payments)
- Resend (transactional emails)

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Useful Scripts

```bash
npm run dev             # start development server
npm run build           # create production build
npm run start           # run production server
npm run lint            # run linter
npm run prisma:migrate  # run Prisma migrations
npm run prisma:seed     # seed database
```
